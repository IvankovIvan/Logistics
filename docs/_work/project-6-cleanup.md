# 📘 Project №6 — Code Cleanup & System Alignment (V1)

---

## 1. Цель

Project №6 — очистка кодовой базы и отключение неиспользуемых частей системы
без изменения архитектуры.

Назначение:

* удалить неиспользуемые точки входа
* зафиксировать фактическое использование системы
* подготовить проект к дальнейшему развитию и описанию

---

## 2. Общая идея

Система уже перешла на analytics слой (Project №3).

OLTP map (Project №1) больше не используется frontend’ом,
но остаётся в коде.

Задача Project №6:

найти → проверить → отключить → зафиксировать

---

## 3. Область работ

Включает:

* API endpoints
* router'ы
* frontend использование API

Не включает:

* изменение архитектуры
* удаление потенциально используемого кода
* изменение ingestion / worker

---

## 4. Текущие выводы

### 4.1 Мёртвый код

По результатам аудита:

* неиспользуемые функции — не обнаружены
* лишние импорты — не обнаружены
* debug-код — отсутствует

---

### 4.2 Project №1 (OLTP map)

Статус:

* /api/map — не используется frontend’ом
* endpoint существует в backend
* router подключен в приложении
* таблицы (warehouses_current, shipments_current) продолжают наполняться

Вывод:

Project №1 не используется клиентом, но остаётся активным в системе

---

## 5. Принятое решение

Project №1 отключается мягко.

Действия:

* router /api/map удаляется из приложения
* endpoint исчезает из Swagger
* код НЕ удаляется:
  * app/routers/map.py
  * app/services/map_builder.py
  * app/services/data_sources/*
* таблицы НЕ удаляются

---

## 6. Ожидаемый результат

После выполнения:

* /api/map → недоступен (404)
* /api/analytics/map → работает
* popup работает
* CSV работает
* система остаётся стабильной

---

## 7. Ограничения

1. Архитектура не изменяется
2. Код не удаляется, только отключается
3. Не затрагиваются ingestion и worker
4. Работы выполняются по шагам

---

## 8. Риски

1. Возможные скрытые зависимости
2. Потенциальное использование OLTP слоя в будущем
3. Переключение datasource может активировать старую логику

Решение:

* отключается только вход (router)
* код сохраняется

---

## 9. Инварианты

1. analytics API остаётся основным
2. frontend использует только /api/analytics/*
3. отключение не влияет на ingestion pipeline
4. система продолжает работать без /api/map
