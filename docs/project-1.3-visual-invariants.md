## Архитектурные инварианты карты

### 1. Общая архитектура

- **1 экран → 1 карта → 1 endpoint (`/api/map`)**
- `page.tsx` — экран-оркестратор
- `MapView.tsx` — lifecycle карты (init 1 раз)
- `MapFacade` — *единственная точка управления MapLibre*
- Нет логики в слоях
- Нет feature-state
- Нет агрегации геометрии

---

## Маршруты (межскладские)

### Геометрия
- **1 API-маршрут = 1 Feature**
- Геометрия **не модифицируется**
- Разведение выполняется **ТОЛЬКО через `line-offset`**
- Две полосы:
  - `forward`
  - `backward`

### Направление
- Direction — **чисто UI-свойство**
- Используется только для:
  - выбора слоя (forward/backward)
  - выбора стрелки (▶ / ◀)
- Direction **не влияет на геометрию**

### Цвет
- **Цвет линии = статус маршрута**
- Источник правды: `ROUTE_STATUS_COLORS`
- **Стрелки всегда нейтральные**
- Цвет — свойство **линии**, не стрелки

### Толщина
- **Фиксированная**
- Семантика «толщина = объём» **отложена на следующий этап**

### Подписи
- **Маршрутные подписи отсутствуют**
- Слой labels **не используется**
- Числовая семантика отложена

---

## Hover

- Hover **разрешён**
- Hover = **только визуальная подсветка**
- **Без popup**
- **Без текста**
- **Без изменения состояния**
- Hover работает строго по `id`

---

## UI-фильтры

- **UI-фильтры маршрутов ОСТАЮТСЯ**
- Фильтрация:
  - только визуальная
  - через `setFilter`
  - без влияния на API и данные
- Persist в `localStorage` разрешён
- Фильтр:
  - переживает `init`
  - переживает `update`
  - не ломает hover

⚠️ Это **осознанное исключение** из исходного инварианта Project №1.

---

## Склады

В Project №1.3:
- Склады — **упрощённые опорные точки**
- Одинаковый визуальный стиль
- **Без кодирования количества**
- **Без числовых подписей**

Инварианты:
- «размер точки = количество»
- числовые подписи складов  
→ **перенесены на следующий этап**

---

## Поставка / продажа

- Визуалы inbound / outbound **НЕ реализуются**
- Стрелки «извне → склад» и «склад → вовне»  
→ **полностью перенесены на следующий этап**

---

## Карта и подложка

- Подложка остаётся **нейтральной**
- Финальная география (RU + KZ + BY, чистка подписей)  
→ **не закрыта в 1.3**
- Свободный pan / zoom
- Жёсткие bounds **не применяются**
- `fitBounds` — **один раз при первом рендере**
