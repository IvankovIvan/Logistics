# 🔍 Code Audit (обязательная проверка)

## 1. Назначение

- Проверка соответствия кода стандартам
- Выполняется:
  - перед коммитом
  - при рефакторинге
  - при добавлении новых endpoint

---

## 2. API (router)

Проверить:

- есть response_model
- нет dict в return
- нет бизнес-логики
- нет SQL
- используются HTTPException

---

## 3. Service

Проверить:

- нет SQL
- нет HTTP (FastAPI)
- нет raw dict в return
- используется mapper

---

## 4. Repository

Проверить:

- весь SQL только здесь
- используются параметризованные запросы
- нет бизнес-логики
- возвращает dict / list[dict]

---

## 5. Mapper

Проверить:

- принимает dict
- возвращает Pydantic
- все поля приводятся к типам
- нет SQL / HTTP

---

## 6. Типизация

Проверить:

- нет object
- нет Any без причины
- есть int(...) / str(...)

---

## 7. Datetime

Проверить:

- нет прямого .isoformat()
- есть проверка:

    value.isoformat() if value else ""

---

## 8. Архитектура

Проверить:

- router → service → repository
- нет обхода слоёв
- нет прямого доступа к БД из router

---

## 9. Антипаттерны (запрещено)

- SQL в service
- mapper в router
- Pydantic в repository
- dict в API
- смешение моделей service и models

---

## 10. Итог проверки

Формат:

    OK / FAIL

Если FAIL:

- указать файл
- указать правило
- указать строку

---

НЕ добавляй лишнего  
НЕ меняй другие файлы
