🎯 Цель этапа

Добавить текстовую семантику складов поверх реализованной геометрии (Project №1.5.a),
не нарушая инварианты current-state и визуальной чистоты.

⸻

📐 Приоритет элементов подписи

Порядок визуальной важности:
	1.	Номер склада
	2.	Имя склада
	3.	Количество (quantity)

Геометрия круга остаётся главным носителем семантики.

⸻

📏 Правила появления подписей (zoom-based visibility)

Используются фиксированные zoom-пороги.

Z < 5

Показываются только circle (без текста).

5 ≤ Z < 6.5

Показывается:
	•	Номер склада

Z ≥ 6.5

Показывается:
	•	Номер
	•	Имя
	•	Количество

⸻

📍 Позиционирование текста

Все подписи:
	•	размещаются справа от circle
	•	с небольшим фиксированным offset вправо
	•	не перекрывают круг

Единый offset для всех складов.

⸻

🔤 Формат текста

На максимальном zoom (Z ≥ 6.5):
№{number} {name}
{quantity}

Пример:

№3 Омск
12500

🎨 Цвет и стиль
	•	Нейтральный тёмный цвет
	•	Без кодирования quantity цветом
	•	Без динамической окраски
	•	Без зависимости от статуса маршрутов
